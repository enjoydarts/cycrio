# サービスロゴの出典

2026-11-02 に公開サービスのロゴと表記揺れを拡充しました。Azure、ConoHa WING、さくらのメールボックス、FranklyMail、Mango Mail、Fantia、FANZA TV、DMM宅配レンタル、Qobuz、TechLib、コミックシーモア、カラリア、各種ナビ・天気アプリ、国内モバイルサービス、映画館の会員サービスなどを補完しています。公式Webサイトのアイコンを優先し、Web上の取得が難しいアプリは提供者を確認したApp Store / Google Playの公式配布画像を使用します。画像は無加工で、参照ページは `sourcePage`、画像URL・提供元・SHA-256は `sources.json` に記録しています。

Azureには公式サイト配信のMicrosoftアイコン、My KIRINにはKIRIN、GMOとくとくBBにはGMOインターネットの企業アイコン、松弁ネットには松屋フーズの公式アプリアイコンを使用します。FANZA TVは公式ヘルプのサービスカテゴリ画像を使用します。YouTubeは明示的なプラットフォーム表記があるメンバーシップに限って割り当て、個人名から推測しません。Yahoo!カーナビの推しドラ関連は[公式案内](https://carnavi.yahoo.co.jp/promo/oshidora/)で確認した製品表記に限定します。空欄・個人ドメイン名・一般的な料金項目など、提供元を識別できない名前は汎用アイコンを維持します。

2026-11-02 に Google Cloud Platform / GCP とレンティオ（Rentio）を追加しました。どちらも公式サイトが指定するカラーアイコンを無加工で使用し、出典URLとSHA-256を `sources.json` に記録しています。Google Cloud は既存の単色カタログ画像を公式配信画像で補完し、Google Workspaceなど他のGoogle製品とは分離します。

2026-11-02 に、にじさんじ FAN CLUB・Obsidian Sync・国内外の主要レジストラを追加しました。にじさんじ FAN CLUB は公式サイトのにじさんじアイコン、Obsidian SyncはObsidian公式のカラーアイコンを使います。にじさんじの共有サイトではファンクラブのパスだけを照合します。お名前.com、ムームードメイン、バリュードメイン、XServerドメイン、スタードメイン、ゴンベエドメイン、Dynadotは公式サイト配信画像を補完し、Cloudflare Registrar、GoDaddy、Namecheap、Porkbun、Gandi、Squarespace Domainsは既存カタログの各ブランド画像を使います。補完画像は無加工で、出典URLとSHA-256は `sources.json` に記録しています。

2026-11-02 に主要キャリア・MVNOの公式サイト配信アイコンを追加しました。NTTドコモ、au、SoftBank、楽天モバイル、ahamo、povo、UQ mobile、Y!mobile、LINEMO、IIJモバイル、IIJmio、mineo、日本通信SIM、b-mobile、HISモバイル、NUROモバイル、イオンモバイル、BIC SIM、LinksMate、TONEモバイルに対応します。IIJモバイルはIIJ公式企業アイコンを使い、IIJmioとは画像を分けています。UQ mobileの公式サイト配信アイコンはUQブランド共通です。IIJとUQの共有ホストはモバイルのパスを明示的に照合し、他製品へ推測で割り当てません。画像は無加工、出典・SHA-256は `sources.json` に保存します。

Xの有料プランは通常カタログのX画像を使います。The X Subscription / X Subscription / Xサブスクリプション、X Basic / Premium / Premium+、日本語表記、旧Twitter Blueから共通のXロゴへ解決します。プラン名は[X公式ヘルプ](https://help.x.com/en/using-x/x-premium)で確認しています。

2026-11-02 に BOOK☆WALKER、カクヨム、カドコミ、KADOKAWA の公式サイト配信アイコンを追加しました。画像は無加工です。BOOK☆WALKER の読み放題（現行コース・旧コース）、カクヨムネクスト・サポーターズパスポート、カドコミの旧称 ComicWalker はそれぞれのサービスロゴを使います。公式案内：[BOOK☆WALKER 読み放題](https://bookwalker.jp/subscription/)、[カクヨム有料サービス](https://kakuyomu.jp/help/entry/faq_subscription)、[カドコミ](https://comic-walker.com/)。企業名の KADOKAWA と各サービスは別の画像で識別します。

このディレクトリは、Simple Icons 16.36.0 に収録されていない主要サービスの補完画像です。公式サイトまたは公式 CDN が配信したアイコンを 2026-11-01 に取得しました。画像そのものは変更していません。取得 URL、SHA-256、権利者・出典は `sources.json` に記録しています。生成時には SHA-256 を検証し、実行時には外部サイトへ問い合わせません。

国内サービスは楽天マガジン、楽天ミュージック、LINE MUSIC、DMM TV、Lemino、TELASA、FOD、WOWOW、radiko、NHKオンデマンド、pixivFANBOX、マネーフォワード ME、freee、ABEMA、ニコニコ、noteを補完しています。楽天とLINEは企業ブランドと各製品の画像を分けています。既存カタログに含まれるサービスも、ここでは公式サイトのカラー画像を優先しています。

Amazon Music（Unlimited・Primeを含む）、Kindle（Kindle+・旧Kindle Unlimitedを含む）、Amazon Kids+、Amazon Photos、Audible、Amazon Prime、Prime Gaming、Amazon Lunaも個別の公式配信画像を使います。Amazon共通画像とPrime専用画像は分離し、白いPrime・Photosの画像は濃い背景に表示します。音楽・読書のプランはそれぞれの製品ロゴを共用します。Kindle+はKindle Plus・キンドルプラスや新旧名称の併記にも対応し、登録済みのサービス名を書き換えずに共通のKindle画像を表示します。名称変更は[Amazon公式案内](https://www.aboutamazon.jp/news/guide/how-to-buy-kindle-books)で確認しています。

メール接続はYahoo!メール（日本）、Yahoo Mail（海外）、iCloud Mail、AOL Mail、Zoho Mail、GMX.com、mail.comの公式配信画像を補完しています。iCloud Mailは公式メールページのiCloudアイコンを使用します。Yahoo! JAPANの赤い画像と海外Yahooの画像は分離しています。IMAP接続では保存済みのサーバー名を既知の接続先と完全一致で照合し、個人の表示名やログイン名をロゴ検索へ送信しません。

国内プロバイダーのOCN、BIGLOBE、So-net、@niftyも、公式メールサイトまたは公式サポートサイトが配信するアイコンを使用しています。利用プラン・IMAP申し込み・接続許可等の条件は接続プリセットの設定案内と公式ヘルプリンクで確認できます。
