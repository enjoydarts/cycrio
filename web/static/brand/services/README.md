# サービスロゴの出典

このディレクトリは、Simple Icons 16.36.0 に収録されていない主要サービスの補完画像です。公式サイトまたは公式 CDN が配信したアイコンを 2026-11-01 に取得しました。画像そのものは変更していません。取得 URL、SHA-256、権利者・出典は `sources.json` に記録しています。生成時には SHA-256 を検証し、実行時には外部サイトへ問い合わせません。

国内サービスは楽天マガジン、楽天ミュージック、LINE MUSIC、DMM TV、Lemino、TELASA、FOD、WOWOW、radiko、NHKオンデマンド、pixivFANBOX、マネーフォワード ME、freee、ABEMA、ニコニコ、noteを補完しています。楽天とLINEは企業ブランドと各製品の画像を分けています。既存カタログに含まれるサービスも、ここでは公式サイトのカラー画像を優先しています。

Amazon Music（Unlimited・Primeを含む）、Kindle（Unlimitedを含む）、Amazon Kids+、Amazon Photos、Audible、Amazon Prime、Prime Gaming、Amazon Lunaも個別の公式配信画像を使います。Amazon共通画像とPrime専用画像は分離し、白いPrime・Photosの画像は濃い背景に表示します。音楽・読書のプランはそれぞれの製品ロゴを共用します。

補完画像について包括的な再利用ライセンスの付与は確認していません。各画像・商標の権利は各権利者に帰属します。これらを CC0 として配布するものではありません。製品識別に使用し、公式提携や権利者の推奨を示すものではありません。Prime Video は専用サイトのアイコン、Microsoft 365 は Office の製品アイコン、Adobe Creative Cloud は Adobe 企業サイトのアイコンで補完しています。Gmail は公式サイト配信のカラーアイコンを優先しています。

通常カタログはビルド用の `simple-icons@16.36.0` からローカル生成します。Simple Icons 自体の CC0 ライセンスを生成先 `/service-logos/LICENSE.txt` に、個別ブランドの公式出典・ライセンス等の metadata を `/service-logos/catalog.json` に保存します。Simple Icons の CC0 はブランドの商標権等を許諾するものではありません。詳細は [Simple Icons の免責事項](https://github.com/simple-icons/simple-icons/blob/16.36.0/DISCLAIMER.md) を参照してください。
