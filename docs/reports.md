# 分析・レポート

サイドバーの「分析・レポート」から、自分が登録したサブスクを集計できます。確認待ちの候補は含みません。通貨をまたぐ合算や為替換算は行いません。

## 支出の目安と内訳

終了済み・期間限定を除く契約の登録料金と周期から、月額・年額を換算します。状態が未確認の契約も含むため、現在の契約状態を合わせて確認してください。金額・通貨・周期が未設定の契約は金額の集計から除外します。明示的に登録した0と未設定は区別します。

月単位は年12か月、日・週単位は年365日として換算します。契約ごとに小数8桁へ四捨五入して合計するため、実際の請求額やカレンダー上の請求回数とは異なります。画面の換算額は小数2桁までとし、表示の丸めがある場合は「≈」（約）を付けます。サービス別の内訳では、同じサービスの契約をまとめ、通貨ごとの構成比と金額順で支出の偏りを確認できます。

## 請求予定

登録済みの次回請求日を使って、今後30日・90日・365日の予定を確認できます。年単位の契約には年次更新の目印を表示します。料金が未設定でも予定は表示し、金額の小計からは除外します。期間は日本時間の今日を含み、終了日は含みません。

日付が過去のまま、または未設定の契約について、請求日を推測して繰り越すことはありません。サブスクの詳細で登録内容を更新してください。

## 見直しシミュレーション

見直したい契約を選ぶと、登録料金に基づく月額・年額の削減目安を通貨別に確認できます。選択はシミュレーション内だけで使います。契約の編集・削除や、サービス提供元での解約は実行しません。

## 月次レポートとCSV

選択した月までの12か月について、契約の履歴に保存された支払い・返金を集計します。返金は差し引き、請求書の金額は別に表示して二重計上を避けます。未記録の月と、記録があって差引額が0の月を区別します。現在の登録料金から過去の支払額を推定することはありません。

対象は、削除されていない契約の有効な履歴です。終了済み契約の履歴も含み、無効化した履歴は含みません。集計月・境界は日本時間です。記録のない支払いや未取り込みのメールは反映されないため、銀行・カードの明細と一致することを保証する会計帳簿ではありません。

画面で取得した月次データをCSVとして保存できます。CSVはUTF-8で、表計算ソフトが式として解釈し得る文字列はエスケープします。メール本文・件名・接続資格情報は含みません。
