# Push通知の有効化ポップアップ

ログイン後に「Push通知を有効にしますか？」を表示する。ユーザーの要望は設定画面のガイドではなく、一般的な「有効にする／あとで」の案内である。

既存のModalを小型表示で再利用する。OneSignalの自動promptは、本人操作前のSDK読込・初期化をしない既存方針と合わないため採用しない。

- 本番のPush設定が利用可能で、対応端末・未有効化の場合だけ表示する。拒否済み、確認中、有効化済み、設定画面や他のダイアログの操作中は表示しない。
- 「あとで」と閉じるは本人・ブラウザー単位で記録し、繰り返し勧誘しない。iPhoneの通常ブラウザーとホーム画面アプリでは案内の段階を分ける。
- 「有効にする」の明示操作後、既存の通知種類を保持してPush同意を保存する。未選択の場合の既定案は更新日と新しい確認待ち。メール・アプリ内・時刻設定を変更しない。
- 保存後に既存のSDK準備・明示的な許可ボタン・受信確認へ進む。保存が不明・競合ならSDKへ進まず通知設定へ案内する。
- iPhoneの通常ブラウザーではホーム画面への追加方法を同じポップアップ内に表示し、設定保存やSDK通信をしない。
- 所有者変更や画面破棄後の古い応答では準備を始めない。既存の端末登録・解除・期限・結果不明の扱いは変更しない。

検証は表示条件と同意・保存順の単体テスト、共通Modalの描画、PC/390/320幅の合成操作、全Webテスト・型・整形・ビルドで行う。
