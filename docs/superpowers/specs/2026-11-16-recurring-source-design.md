# 承認済み契約への継続決済の紐付け

登録・紐付けを承認済みの契約について、同じメール接続から届く同内容の継続決済は確認を繰り返さず、自動で根拠へ追加する。料金・プラン・周期などの変更、新規契約、曖昧な照合は引き続き確認待ちとする。

照合には本人が承認した元の抽出内容を使い、自動で追加した根拠だけから対象を広げない。決済日・対象期間・次回請求日は月ごとに変わるため照合から除外する。未取得のnullと旧形式の項目欠落は同じとする。他の抽出値は一致を要求し、既存契約の現在の料金・プラン・周期に既知の不一致があれば追加しない。メール接続と所有者を一致させ、候補契約が複数ある場合、終了・削除済み契約、除外済み・予約変更中・古い解析結果は対象外とする。

旧解析で自動更新の項目を記録していなかった場合、同内容の継続決済に「自動更新あり」が追加されても、契約内容を変更せず根拠へ追加できる。承認済み根拠に「自動更新なし」がある場合や、現在の契約で自動更新を明示的に停止している場合は、この互換処理を使わず確認待ちに残す。自動更新なしや新たな無料期間・終了日の情報は自動承認しない。

Workerは保存済み結果だけを使用する。契約の新規作成や内容の変更、メール再取得、AIの再呼び出しは行わない。根拠の追加・版更新・監査を同一トランザクションで実行し、次回請求日の起点は変更しない。請求履歴は既存の自動記録設定と重複検証に従う。既存の同内容の確認待ちも対象とする。

所有者・接続・処理結果・契約の順にロックし、再実行と手動操作との競合で二重登録しない。通知は自動紐付け後の残る候補を扱い、継続決済だけで新しい確認待ち通知を作らない。
