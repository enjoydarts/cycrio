# 契約変更の予約反映

[READMEへ戻る](../README.md)

「来月から料金が変わる」など、メールから抽出された将来の効力日を持つ変更を、本人の確認後に予約できます。外部サービスの契約を変更する機能ではなく、Cycrio内の登録内容を更新する機能です。

## 予約する

1. 確認候補から既存の契約を選び、「契約の変更を確認」を開きます。
2. 将来の効力日がある場合は「効力日に予約する」へ進みます。
3. 効力日と、変更する項目・根拠をそれぞれ確認し、選択した変更を予約します。

日付は元の抽出情報の効力日と一致する必要があります。料金・通貨などは本人が選んだ項目だけを反映し、不明な値を補完しません。値上げの効力日で契約の元の開始日を上書きしません。将来の効力日がない場合は、従来の即時反映を使用します。

予約受付時には現在の契約内容を変更しません。料金やレポートも現在の契約内容を参照し、予約の反映後に更新されます。一つの契約で有効な予約は一件です。予約中の根拠は別の登録・承認・不要判定に使えないよう確保し、未確認候補の一覧から除外します。

## 反映時期と再確認

効力日は日本時間（Asia/Tokyo）の日付です。その日を迎えた後、Workerが処理を確認して反映します。秒単位の実行時刻を保証するものではなく、停止中に日付を過ぎた場合は再起動後に対象を処理します。

反映直前に、予約時の契約version・元の根拠・選択した値を再確認します。予約後の手編集や根拠の変更などを検知すると、上書きせず「要再確認」で停止します。契約の削除時には予約も取り消します。複数Workerによる処理や再起動があっても、契約更新・予約の状態・変更履歴・監査は同じトランザクションで一度だけ確定します。追加のLLM問い合わせは行いません。

## 確認・取消

契約詳細の「契約変更の予約」で、予定日・状態・予約した項目・元の根拠を確認できます。

| 状態 | 内容 |
| --- | --- |
| 予約中 | 効力日以降の反映待ち |
| 反映済み | 選択した内容を反映済み。通常の変更履歴にも記録 |
| 要再確認 | 契約の更新や根拠の変更などにより自動反映を停止 |
| 取消済み | 予約を取り消した状態 |

予約中・要再確認の予約は、内容を確認して取り消せます。現在の契約内容は変えず、確保していた元情報を候補に戻します。要再確認の予約をやり直す場合は、取消後に最新の内容を確認して再承認してください。契約そのものを削除する場合も、その契約の有効な予約を同時に取り消して元情報を解放します。反映済みの変更を取消操作で巻き戻すことはありません。

予約受付の応答が確認できない場合は、同じ要求と確認済みの日付を保持して再確認します。異なる要求で自動的に重複予約しません。

## 保存と削除

承認した差分と根拠を予約時のスナップショットとして保持します。元の処理結果の変更も防ぎ、予約後の再解析で承認内容を書き換えません。各操作は本人の契約だけを対象にします。退会時は予約・根拠の確保情報も削除し、匿名監査には個人の情報や抽出内容を残しません。

実装は`internal/subscriptions/scheduled_changes.go`、`internal/database/subscription_scheduled_changes.go`、migration `00045`、Workerの既存DB処理ループを参照してください。
