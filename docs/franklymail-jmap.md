# FranklyMailのJMAP接続

Cycrioの「メール接続」でサービスに「FranklyMail（JMAP）」を選び、メールボックスの完全なメールアドレスとアプリパスワードを登録します。FranklyMailのダッシュボード用パスワードや管理APIキーは使えません。

## 設定

1. FranklyMailの「Settings → App passwords」でメールボックス用のアプリパスワードを発行します。
2. CycrioでFranklyMailを選び、メールアドレスとアプリパスワードを入力して保存します。
3. 接続テストを行い、取得されたフォルダーから解析対象を選択します。
4. 取り込み期間を指定し、既存の取り込み・解析操作または自動取り込み設定を利用します。

Session URLは `https://jmap.franklymail.com/jmap/session` に固定しています。セッションが示すAPI URLは、公式の `jmap.franklymail.com` と `mx1.franklymail.com` のHTTPSのみ許可します。任意ホスト・ポート指定、リダイレクト先への認証情報転送は認めません。追加の環境変数や管理APIキーは不要です。

公式仕様とアプリパスワードの手順は[FranklyMailのJMAPガイド](https://franklymail.com/guides/jmap)を参照してください。

## 同期とデータの扱い

- `Mailbox/get`、`Email/query`、`Email/get`、`Email/changes` の読み取りのみ実行します。既読化・移動・削除・メール送信は行いません。
- 過去メールは日本時間の日付範囲で取得し、新着はJMAPの変更状態から取得します。状態が失効した場合は対象フォルダーの再走査へ切り替え、走査開始時点の状態を保持して、その後の変更を取得します。
- 同じ接続内で複数フォルダーに属する同一メールは、共通のメールIDによって重複取り込みを防ぎます。
- アプリパスワード、メールID、同期カーソルは既存の所有者分離・暗号化保存を使用します。保存済みパスワードは再表示しません。
- 本文取得時にも対象フォルダーへの所属を確認します。添付ファイルや添付された転送メールの本文は解析対象から除外します。
- 優先する本文形式に複数の本文パートがある場合は、一部だけを解析せず、未対応の本文形式として扱います。
- 同期中に検索結果の状態が変わった場合は、そのページ走査を先頭から再開します。メールが頻繁に増減するフォルダーでは、過去メール走査の完了に時間がかかる場合があります。

既存のIMAP接続は自動で切り替わりません。既存接続の方式を変更することもできません。JMAP接続を新規に作成する場合は、既存接続の自動取り込みを停止し、対象期間の重複に注意してください。別接続・別方式間でのメールの重複排除は保証しません。

## 運用と受入確認

DB migration 48は既存テーブルの接続方式制約に `franklymail` を追加します。テーブルや列の追加、既存データの変換はありません。FranklyMail接続が残っている場合は、旧制約へ戻すDownを拒否します。

合成テストでは認証・フォルダー・日付境界・差分同期・状態失効・本文取得・所有者分離・暗号化・停止と削除・画面操作を確認します。実メールボックスでの受入では、接続成功、フォルダー選択、過去メールの取り込み、新着メールの取り込み、候補確認、アプリパスワード無効化後のエラー表示を確認してください。実メールの解析には、利用者が同意したAIプロバイダーへの本文送信と通常の利用原価が伴います。
